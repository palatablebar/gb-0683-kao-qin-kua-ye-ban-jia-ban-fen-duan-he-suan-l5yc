# 夜班工时与工资

班次属于shift_day；计划结束时间不大于开始时间时跨到次日。打卡是带偏移的时间，先存UTC，再用Asia/Shanghai拆分实际日历日。休息区间按夜班日期归属处理，先从实际工作区间扣除。单班最多18小时，打卡须为整分钟。缺IN或OUT整班隔离，不猜补卡。

按实际日历日判断法定假日、周末，法定假日优先3倍、周末2倍、工作日8小时内1倍、超过8小时1.5倍；正常分钟按同员工同日累计，跨班片段共享阈值。参数holidays可传日期列表，默认仅2026-10-01。金额按片段Decimal计算到分，paid为实发工资，差额为应发减实发。此规则用于样例计算，不替代当地劳动法规。

## 通用采信约定

CSV按UTF-8 BOM、UTF-8、GB18030回退，保留逻辑记录结束行号；引号内换行由CSV解析。重复表头单独计数，列数不齐隔离。编码与ID按字符串保形。缺失哨兵为 `-`、`N/A`、`NULL`、`未知` 与空串；不得作为零。数值先NFKC归一、去千分位，再用Decimal。日期采用ISO；时间必须带偏移并转UTC。空文件、全空行、仅表头分别返回EMPTY_FILE、BLANK_FILE、HEADER_ONLY。

重复键为(id,version)，完全相同行去重；同键内容冲突则整组隔离，不取最后一行。行数对账：输入=采纳+隔离+空行+重复表头+完全重复。运行幂等键由输入字节、参数与规则版本计算。

同一员工/归属日/方向的最高版本若有时刻、时薪、班次、休息或实发金额冲突，则整班隔离；选中IN与OUT的时薪、班次起止与休息起止也必须完全一致。

## 月度多模板裁决（M8 月度发布）

考勤机分批升级后，同一结算月允许并存两类字段模板，模板只按**源文件表头签名整体认定一次**，不逐行猜测：

- **v1 旧字段模板**：含 `break_start`、`break_end`，无 `break_minutes`。打卡必须整分钟（带秒按 RANGE 隔离），休息用起止时刻表达。
- **v2 新字段模板**：含 `break_minutes`，无休息起止列。打卡允许带秒；`break_minutes` 必须为非负整数，否则 NUMBER 隔离。
- 两套休息字段并存、均缺失、共用必填列缺失或表头重复：整份文件以 `TEMPLATE` 拒收，不进入月度结果、不隔离其中任何一行。

两类行归一为同一班次模型后再配对，同一员工/班次日不会被拆成两套语义。v2 不猜测固定休息钟点：休息分钟按**实际打卡区间的中点居中**合成窗口（奇数秒时起点向下取整，保证窗口落在区间内），休息分钟超过打卡区间按 RANGE 隔离。v2 工作时长按秒折整分钟向下截断计薪，原始带秒时刻在页面与导出中保留。

月度结果以来源集指纹版本化：来源按 (月份, 文件名) 登记，内容哈希变化即来源变动；数据集指纹由全部来源哈希、参数与规则版本计算，同源重算幂等、记录不增不减。来源变动后重算产生新数据集，旧发布数据集标记 `superseded=1` 但保留可查；发布是 `ledger_published` 指针的条件原子切换，仅复核通过且未作废的数据集可发布，发布中断或新版未发布期间旧版继续有效。所有版本的原始打卡与隔离原因均保留。

核对页面 `/m8_ledger` 与月度导出 CSV 使用同一份数据集：逐来源列出解释方式（模板、编码、采纳/隔离/实发）、班次的 IN/OUT 来源与原始打卡、应付片段与金额、隔离追溯与数据集版本链；仅已发布数据集可导出。
